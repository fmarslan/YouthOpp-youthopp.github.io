# Privacy and source policy

The catalog requires no account and collects no application details. Applications happen on the original publisher's website.

## Attribution and reuse

Every record credits and links to its source. Short summaries preserve source language. Publishers remain authoritative for deadlines and application conditions. Collection needs a source-specific access and reuse assessment; public availability is not automatic permission to reproduce content.

## Analytics

Analytics are disabled by default. Enabling a tracker requires documenting its service, collection, retention and applicable consent before publication.

## Public contributions

GitHub logins and public contribution counts may appear on the contributors page. These are activity indicators, not skill assessments. Request corrections through the project issue tracker.

## External websites

External sources have their own privacy and usage policies.
