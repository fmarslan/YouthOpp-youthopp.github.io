# Accessibility and quality

The catalog works without JavaScript. Category and destination links load complete static HTML pages. Keyboard users can skip directly to the main content and receive a visible focus outline.

## Content and layout

The interface is English. Source titles and summaries preserve their original language with a language attribute. Unknown information is explicitly marked rather than guessed. Responsive layouts support narrow screens; research tables can scroll horizontally.

## Checks

Automated tests verify pagination, route generation, escaping, original-source attribution and malformed catalog rejection. Independent QA audits internal links, headings and metadata. The primary text color combinations pass WCAG AA contrast calculations.

## Limitations

Rendered browser testing was unavailable in the initial development environment. Automated checks and CSS inspection do not establish full WCAG compliance. Keyboard, screen-reader and mobile browser review remain ongoing quality tasks.
